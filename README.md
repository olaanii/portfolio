# Olani Shambel — Portfolio

Personal portfolio for Olani Shambel, a Flutter developer exploring Web3 and AI. The site presents selected public work, a stack grouped by use, and contact links in a restrained, monochrome layout.

## Featured work

- [Veyra](https://github.com/olaanii/veyra) — AI-assisted project planning.
- [Afan Oromo Programming Language](https://github.com/olaanii/afan-oromo-PL) — beginner language that translates Afan Oromo into Python.
- [FLUXX NFT Marketplace](https://github.com/olaanii/Fluxx---NFT-Minting-and-Marketplace) — Sepolia NFT marketplace prototype.
- [BIRR Blockchain](https://github.com/olaanii/birr) — Go blockchain prototype with P2P and JSON-RPC.

## Run locally

```bash
npm install
npm run dev
```

The page is served at [http://localhost:3000](http://localhost:3000). The public portfolio content lives in `app/page.tsx`; styles are in `app/page.module.css` and `app/globals.css`.

## Stack

Next.js, React, TypeScript, CSS Modules, next-themes, and Lenis. Profile artwork and the existing dog sprite are stored in `public/`.

`profile/README.md` contains the matching GitHub profile README draft. GitHub displays it on the profile when it is copied to a repository named `olaanii/olaanii`.
